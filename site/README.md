# Сайт-візитка — Ірина Кузуб (IRA | Pilates · Fly Stretching)

Односторінковий **link-in-bio** сайт на основі Instagram-профілю
[@irinaa.k1](https://instagram.com/irinaa.k1). Один файл, без залежностей —
відкривається будь-де й миттєво хоститься.

## Як подивитися
- Просто відкрий `index.html` подвійним кліком у браузері, **або**
- локальний сервер: `python3 -m http.server 8080` → `http://localhost:8080`

## Як опублікувати (безкоштовно)
- **GitHub Pages:** Settings → Pages → гілка → папка `/site`.
- **Netlify / Vercel:** перетягни папку `site/` — і готово.
- Посилання встав в Instagram у поле «сайт».

## ЩО ЗАМІНИТИ на реальне (5 хв)
Все нижче позначено коментарями прямо в `index.html`:

1. **Фото.** Поклади у `site/assets/`:
   - `avatar.jpg` — аватарка (квадрат, ~400×400);
   - `photo-1.jpg` … `photo-6.jpg` — для галереї;
   - `og.jpg` — прев'ю для месенджерів (1200×630).
   Поки файлів немає — показується лотос-плейсхолдер, тож сайт виглядає
   завершеним одразу.
2. **Telegram.** Кнопка Telegram веде на `https://t.me/` — заміни на свій
   `https://t.me/USERNAME`. Якщо Telegram немає — видали цю кнопку.
3. **Розклад.** Зчитано з поста: Стретчинг Пн/Чт 10:00 та Вт/Пт 18:00.
   Перевір і онови за потреби (блок `#schedule`).
4. **Запис.** Головні кнопки ведуть у директ Instagram (`ig.me/m/irinaa.k1`).
   Якщо приймаєш запис інакше (Telegram, телефон) — зміни `href`.
